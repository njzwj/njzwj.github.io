# This is a statically generated blog by Next.js

Minimal serif journal with a chronological article list, optional photographs,
three bilingual tags, light/dark mode, equations, Mermaid diagrams, English
Markdown editions, and Disqus comments.

See [Writing and setup](docs/writing.md) for Markdown fields, diagrams,
translations, and comment configuration.

## Support of draft

Name posts with suffix `_draft` to make it a draft post. This post will not be shown in the production build.
